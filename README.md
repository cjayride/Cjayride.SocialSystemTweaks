# SocialSystem Tweaks

Client patch for [M2Valheim SocialSystem](https://thunderstore.io/c/valheim/p/M2Valheim/SocialSystem/).

- Party / friend invite prompts can appear while you are in combat.
- HP numbers on the party HUD health bars (current / max by default).

See [Package/README.md](Package/README.md) and [CHANGELOG.md](CHANGELOG.md).

Copy `Environment.props.example` to `Environment.props` and point at your Valheim / SocialSystem / Jotunn paths before building.
